언리얼 수어 모캡 데이터 수집 가이드

SignBridge · Unreal Engine 5.8 MetaHuman Animator
v1.0 · 회전 애니메이션(AS_MHP) 추출 workflow
이 문서가 하는 일: 실제 수어 영상 한 개를 → 언리얼 MetaHuman Animator로 처리해 → 손가락 회전까지 포함된 애니메이션 파일(AS_MHP_...)을 만들어 저장하기까지의 전 과정. 각자 단어를 나눠 맡아 병렬로 데이터를 늘리는 것이 목표. 결과물 = 단어별 회전 애니메이션 애셋.
⚠ 시작 전 반드시 읽기 — 하드웨어 & 저작권
  • GPU: MetaHuman Animator의 처리(Process)는 NVIDIA(CUDA)에 최적화됨. AMD 라데온은 매우 느리거나 실패할 수 있음 → 먼저 짧은 단어 1개로 "처리가 끝까지 되는지" 테스트할 것.
  • 메모리: VRAM 8GB는 빠듯함. 작업 중 브라우저·다른 프로그램·Live Link Hub 전부 닫기. 메모리 부족 경고가 뜨면 Cancel 후 프로그램 정리.
  • 저작권: 유튜브 등 타인 영상은 기술 테스트용으로만. 데모·제품에 넣을 단어는 직접 촬영했거나 사용 권리를 확보한 영상만 사용.

단계별 상세 절차 · 자주 막히는 지점 해결법

단계별 상세 절차

1영상 Ingest — 소스 영상 가져오기
  • Content Browser에서 signdemo 폴더로 이동.
  • 우클릭 → MetaHuman → Capture Data (Footage) 생성, 또는 상단 Capture Manager로 영상 파일을 Ingest.
  • 수어 영상 파일(mp4 등)을 지정 → 처리가 끝나면 Footage Capture Data 애셋이 생성됨.
2MetaHuman Performance 애셋 생성
  • signdemo에서 우클릭 → MetaHuman → MetaHuman Performance 생성. 이름 예: MHP_WORD1501_Body.
  • 더블클릭해서 열고, Details 패널에서 Footage Capture Data에 1단계 애셋을 지정.
  • Processing Parameters에서 트래킹 종류 설정:
    • Face + Body(권장): Facial·Body Tracking 둘 다 켜기. Face Detector·Face Solver는 Small 변형 선택(안 보이면 Show Engine Content 켜기).
    • 손·팔 위주라면 Body Tracking 중심, Head Movement 필요시 켜기.
3Process — 처리(솔브)
  • 타임라인에서 필요한 구간만 남기고 앞뒤를 트림.
  • Process 버튼 클릭 → 프레임별로 몸·손·얼굴을 추적. 시간이 걸림(특히 AMD GPU는 매우 느림).
  • 완료되면 프리뷰에서 뼈대/메시가 영상처럼 움직이는지 확인.
⚠ AMD(RX 6600) 첫 테스트: 여기서 무한 대기·에러·비정상 종료가 나면, 이 PC로는 Process가 어렵다는 뜻. 그 경우 모캡은 NVIDIA PC가 전담하고, AMD PC는 영상 준비·검수·MP4 변환·코드 작업을 맡는 분업으로 전환.
4Export Animation — 회전 애니메이션 내보내기
  • Export Animation 클릭 → 이름·저장 위치 지정(signdemo).
  • 옵션은 기본값 유지: Face/Body Export 체크, Enable Head Movement, Auto Save, Export Range=Processing Range, Unsolved=Last Valid Frame, Curve=Linear, Remove Redundant Keys.
  • Export Skeleton은 Performer Skeleton(기본)으로 두기 → 나중에 MetaHuman(Skye 등)에 적용 가능.
  • Generate 클릭. 완료되면 signdemo에 AS_MHP_단어_Body(애니메이션)와 SK_MHP_단어_Body(마네킹 메시)가 생성됨.
✅ 여기서 나온 AS_MHP_...가 진짜 결과물 — 이 안에 뼈 회전값(손가락 포함)이 들어있음. 이게 우리가 원하던 "회전 데이터".
5검수 & 저장·공유
  • AS_MHP_... 더블클릭 → 재생(space)해서 동작 확인. 특히 손가락이 원본 영상처럼 자연스러운지 집중 확인.
  • 이상하면(손 뒤틀림·프레임 튐) 원본 영상 품질 문제일 가능성 → 더 좋은 소스로 재시도.
  • 정상이면 팀 공유 위치(공유 드라이브/깃 LFS 등 팀 합의)로 AS_MHP_단어와 SK_MHP_단어를 함께 전달.
  • 작업 기록: 단어명 · 원본 출처 · 품질(상/중/하) · 손가락 정상 여부를 공유 시트에 남기기.

자주 막히는 지점 (사용자 실경험 기반)

증상해결
메모리 부족 경고 (10GB 필요, 가용 부족)Cancel → 브라우저·Live Link Hub·타 프로그램 종료 후 재시도. 고품질 MetaHuman은 후순위로.
캐릭터/메시를 뷰포트로 드래그하면 빨간 금지 아이콘MetaHuman은 뷰포트 직접 드롭 불가. 애니메이션(AS_MHP)은 Sequencer에 드롭 가능 — 캐릭터가 필요하면 레벨 시퀀스 경유.
재생하면 배경 검고 뼈대만 보임메시가 없는 추출용 상태일 수 있음. 검수는 AS_MHP 애셋 자체를 열어 재생하면 됨.
Play 눌렀더니 종료 안 됨(PIE 상태)Esc 또는 정지(■) 눌러 재생 모드 종료 후 재시도.
Face Detector/Solver가 목록에 없음Content Browser 설정에서 Show Engine Content 켜기.
손가락이 바닥에 떨어지거나 뒤틀림원본 영상에서 손이 겹치거나 화면 밖으로 나감 → 손이 잘 보이는 다른 영상으로 교체.
파일명 규칙(팀 합의 예시): 애니메이션 AS_MHP_<단어ID>_Body · 메시 SK_MHP_<단어ID>_Body · 퍼포먼스 MHP_<단어ID>_Body. 단어ID는 팀에서 정한 표(한글단어↔ID) 기준으로 통일.
✅ 분업 제안: NVIDIA PC = 모캡(Process/Export) 집중 / AMD PC = 소스 영상 선별·구간 컷·검수·MP4 렌더·GUI 코드. 이렇게 나누면 서로 기다리지 않고 병렬 진행 가능.
